Build a complete, production-ready e-commerce web application for a Roblox game item store named **KING CAMERA SHOP** (selling Camera Tower Defense units), modeled after modern Thai automated game-store layouts (clean navbar with Home, Top-Up, Shop/Cart, Profile, and footer with Terms, Privacy Policy, and Cookie Settings).

### 1. Tech Stack

### 4. Authentication System (No Phone Number Required)
Remove all phone number fields from user sign-up and sign-in. Support **Username and Email only**:

**A. Sign In (Existing Account)**
- Single flexible identifier input accepting **Username or Email** (server normalizes email to lowercase and queries matching unique column).
- **Password** input with show/hide visibility toggle.
- Anti-bot challenge (Cloudflare Turnstile / hCaptcha) before submission.
- Generic error messages on failure ("Invalid credentials" / "ข้อมูลเข้าสู่ระบบไม่ถูกต้อง") to prevent user enumeration.

**B. Create Account (Registration)**
- **Username** (alphanumeric/underscores, 3–20 chars, unique).
- **Email** (valid email format, normalized lowercase, unique).
- **Password** (minimum 8 characters, enforcing uppercase, lowercase, number, and symbol, with live strength meter).
- **Confirm Password ("Make sure password")** with real-time match validation both client-side and server-side before creating the account.

### 5. Security & Anti-Hacking Protection
Build defense-in-depth protections against account takeovers, brute force, and balance exploits:
- **Password Security:** Hash all passwords with **Argon2id** (or bcrypt cost >= 12). Never log or return password hashes.
- **Session Management:** Store sessions in `HttpOnly`, `Secure`, `SameSite=Strict` cookies using short-lived access tokens + rotating refresh tokens stored hashed in the database. Include an "Active Sessions / Log Out All Devices" button on `/profile`.
- **Brute-Force & Bot Defense:** Enforce IP-based and account-based rate limiting (max 5 failed login attempts per 15 minutes with exponential lockout) on `/login`, `/register`, and `/topup` endpoints.
- **Web Attack Prevention:**
  - Parameterized Prisma queries exclusively to block SQL Injection.
  - Strict Zod input sanitization plus security headers: Content Security Policy (CSP), `X-Frame-Options: DENY`, `X-Content-Type-Options: nosniff`.
  - CSRF protection on all state-changing endpoints.
- **Anti-Race-Condition & Anti-Tampering:**
  - Never trust prices, totals, or balances sent from the frontend; compute all amounts server-side.
  - Wrap every top-up credit and purchase in a PostgreSQL interactive transaction with row-level locking (`SELECT ... FOR UPDATE`) to block double-spend and parallel-request exploits.
  - Log immutable security audit events (user ID, masked IP, user agent, action, timestamp) for all auth and financial actions.

**Left Column — Interactive Step Panels:**
- **Step 1: Channel**
  - Selectable Bento glass cards with specular active borders:
    1. **TrueMoney Wallet — Gift Voucher (ซองอั่งเปา)** (Instant automatic credit)
    2. **TrueMoney Wallet / PromptPay — QR Code** (Scan & verify via Slip API or Payment Gateway webhook)
- **Step 2: Amount**
  - Heading: **Amount to top up**
  - Subtext: **Enter any amount you plan to transfer.**
  - Numeric input labeled **Amount (THB)** with placeholder `Enter amount, e.g. 150` and fixed `฿` currency indicator.
  - Quick-pick section labeled **Or pick a quick amount** with a clean responsive button grid containing these exact presets:
    - `50฿`, `100฿`, `200฿`, `300฿`, `500฿`, `1,000฿`, `2,000฿`, `5,000฿`
  - *(Note: For Gift Voucher channel, clearly note that the credited amount always matches the exact verified baht inside the redeemed voucher so users never lose money even if the estimate differs.)*
- **Step 3: Payment info**
  - **If Gift Voucher (ซองอั่งเปา) selected:** Input field for TrueMoney voucher URL (`https://gift.truemoney.com/campaign/?v=...`) with live format validation and short guide on creating a 1-person voucher link.
  - **If QR Code selected:** Backend generates a dynamic **EMVCo PromptPay / TrueMoney QR Code** locked to the exact THB amount from Step 2 with a 15-minute monospace countdown timer, Save QR button, and a **Slip Upload** dropzone (or automatic webhook listener mode).
- **Step 4: Confirm**
  - Clean review panel showing Channel, Target Amount, and Voucher Link / Uploaded Slip preview, plus anti-bot verification and a primary **Confirm Top-Up** button.
  - **Guaranteed Credit Backend Logic:**
    - Check `UNIQUE` constraint on `external_ref` (voucher hash or slip `transRef`) so no voucher or slip can ever be reused.
    - Insert a `PENDING` transaction *before* calling external APIs (shop owner's TrueMoney phone / PromptPay ID / Slip API key stored strictly in server `.env`, never exposed to client).

    - On network timeout, mark as `NEEDS_REVIEW` and return a clear Tracking ID so an admin can verify and credit immediately—ensuring no user loses money.
- **Step 5: Done**
  - Confirmation glass receipt card displaying Status (`Completed` or `Needs Review`), Reference ID, Channel, Exact Amount Credited (`+XXX.XX ฿`), Updated Wallet Balance, and action buttons: **Go to Shop** and **View Profile History**.
